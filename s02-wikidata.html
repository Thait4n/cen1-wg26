Documentaires français avec affiche

Séance 2 – La récolte de données. Requête SPARQL sur Wikidata pour récupérer des films documentaires d'origine française qui ont une affiche, avec leur réalisateur et leur date de sortie.

Code SPARQL

#defaultView:ImageGrid
SELECT DISTINCT ?film ?filmLabel ?film_poster ?directorLabel ?date WHERE {
  ?film wdt:P31 wd:Q11424;
    wdt:P136 wd:Q93204;
    wdt:P495 wd:Q142;
    wdt:P3383 ?film_poster.
  OPTIONAL { ?film wdt:P57 ?director. }
  OPTIONAL { ?film wdt:P577 ?date. }
  SERVICE wikibase:label { bd:serviceParam wikibase:language "[AUTO_LANGUAGE],fr,en". }
}
LIMIT 100

P31 = nature de l'élément, Q11424 = film · P136 = genre, Q93204 = film documentaire · P495 = pays d'origine, Q142 = France · P3383 = affiche · P57 = réalisateur · P577 = date de publication.
